# SEC-2_SA1_SOLO_PINILI
Because I was not able to download a Eth dataset that goes to 2026 (There is one that requires rearchive, and github has one in 404 error.) I downloaded a dataset that goes to 2025, 

Bitcoin Dataset:
https://www.kaggle.com/datasets/mczielinski/bitcoin-historical-data

Ethereum Dataset:
https://www.kaggle.com/datasets/popcornanalytics/ethusd-1minute-ohlcv-2017-2025

The Kolmogorov-Smirnov test produced a p-value less than 0.05, indicating that Bitcoin returns do not follow a normal distribution. The Shapiro-Wilk test was used to evaluate normality of the Ethereum 5-minute returns. The conclusion depends on the p-value produced by the test.
